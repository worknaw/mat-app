# Product

## Register

product

## Platform

web

## Users

Primary audience: Personal media enthusiasts tracking movies, TV series, anime, and books/manga in a single unified hub.
User context: Daily viewing sessions where users browse continue-watching shelves, log episode progress, check recommendations, and search titles.
Job to be done: Track media consumption with zero friction on a cinematic, Netflix-style workstation equipped with instant episode controls and hotkeys.

## Product Purpose

A cinematic, Netflix-inspired personal media tracking application and analytics dashboard built to log progress, visualize watch history, organize custom collections, and streamline episode tracking.

## Positioning

The most cinematic, high-speed personal media tracking hub combining a full-bleed Netflix UI with instant keyboard controls and rich viewing analytics.

## Brand & Personality

- Personality: Cinematic, Premium, Immersive
- Design References: Netflix Web Interface (deep black canvas #141414, Netflix red #e50914 accents, full-bleed hero spotlight, horizontal poster shelves)
- Anti-References: Cluttered enterprise dashboards, light mode tables, generic bootstrap cards

## Accessibility & Inclusion

- Target WCAG AA color contrast ratios across dark mode surfaces
- Support for `prefers-reduced-motion` CSS rules
- Full keyboard shortcut navigation (`Ctrl+K` for command search, `Space` for quick episode logging)
- Primary language for agent questions, discovery interviews, and UI copy: **Thai (ภาษาไทย)**
